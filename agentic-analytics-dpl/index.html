First version

What's in it

MCP client→ Dash · checks the user can see the site→ Athena · role limited to one site→ Customer's S3 bucket, read in place

One Glue table per network

Built from the customer's files, keeps their custom fields (extra_data). Holds no data, only where the files are.

Provisioned by Dash

Success Admin registers the network, a daily sync picks up new buckets and fields, the Django admin shows each one.

Two MCP tools

query_dpl_events and get_dpl_fields. A site without DPL gets a message, not an error.

Cost

Pennies per thousand questions

Athena

$5 / TB read

Reads only the columns it needs. Each query bills the 10 MB minimum: about $0.00005.

S3

$0 transfer

Same region, so reading costs no transfer. Only tiny per-request fees.

Glue

Free at our size

Billed per 100,000 stored objects, not per read. We store dozens.
